Limits · read this before you believe us

What is real, what is simulated, and where it breaks.

A prototype earns trust by saying where it stops. Everything below can be checked on the other pages.

Real, working code

  • The decision engine: evidence nowcast, scoring, confirm-call order, sickest-first queue, en-route re-routing.
  • The ranking only reads fleet observations. A test fails if it ever reads hidden hospital state.
  • Report triage: keyword extraction plus a trained severity classifier, with an injury and chest-pain safety floor.
  • FastAPI backend, WebSocket live state, SQLite storage of runs, evidence and decisions, CSV export.
  • Live Hyderabad rainfall from Open-Meteo, when the network allows.

Simulated

  • The city: a stylised grid with Hyderabad area names, not real roads or travel times.
  • Hospitals, bays, walk-in rates and refusals are generated. No real hospital data is used.
  • Ambulance GPS and crew taps are generated by the simulator, then read by the engine as if they were real.
  • Confirm calls are answered from the simulated hospital's true state, or by you.
  • Severity model is trained on synthetic reports and scored on 36 hand-written ones: optimistic.

Known limits

  • Quiet city: no significant gain (-0.7 turn-aways per 100, 95% CI crosses zero). RightCall helps when hospitals choke.
  • If refusals are random and unrelated to load, turn-aways still fall but average time is 3.5 min worse than without evidence.
  • If hospitals answer the phone wrongly 1 time in 4, average time is 1.9 min worse than phone-ahead.
  • A simpler estimator predicts waits better (error 7.7 vs 9.0 min) yet decides worse; we keep the one that decides better.
  • Needs fleet GPS and a crew "refused" button. No real 108 data, real roads or 108 integration yet. No flood or fire incident types.
  • No Telugu or Devanagari script: Roman-letter Telugu and Hindi only. Triage critical recall 0.93 on reports written after review.

Edge cases we tested

Each has a regression test or a scripted browser check (28 tests, 56 browser checks in release 1.1.0). Try any of them yourself.
