Proof · is it just one lucky city?

Run it on cities nobody tuned it for.

Each benchmark city is a fresh seed the engine was never tuned on, run for three simulated hours with random hospital surges. Four policies see exactly the same patients. One of them is RightCall with its fleet evidence switched off, so you can see what the mechanism itself adds.

The four policies

  • Nearest: today's common practice. Drive to the nearest capable hospital; if refused, drive to the next nearest.
  • Phone ahead: the honest non-AI baseline. Phone the nearest hospital first, then the next, until one says yes.
  • RightCall, evidence removed: the same engine and the same confirm call, but every hospital looks average. If this did as well, the fleet evidence would be pointless.
  • RightCall: rank on fleet evidence, phone the top pick, sickest first, re-route if it saves more than 5 minutes.

Read the turn-away column first. It is the robust result. Average time also improves in most cities, but not in all of them, and the strip chart shows every city so you can see the spread.
